# 2D 战斗测试版

这是《西游：八十一劫》的竖屏 2D 验证原型，刻意保持为单文件、无依赖、无持久化的快速测试版。当前角色使用 Canvas 矢量初稿：圆润比例、粗描边、鲜明色块，主题转译为西游卡通风格，不依赖外部素材加载。

## 运行

直接双击 `index.html`，或使用任意静态文件服务器打开 `prototype-2d/index.html`。不需要安装 Unity、npm 或额外资源。

## 操作

- `WASD` / 方向键：移动悟空
- 手机/触屏：拖动左下角摇杆
- `F1`：显示攻击扇形、tick、坐标和命中计数
- `V`：切换轻量命中/受击反馈
- `R`：重开当前观察局

## 技能构筑与加点

- 每局固定 7 个技能位：2 个角色固定技（1 主动、1 被动）+ 3 个核心法宝 + 2 个额外特效。
- 开局从随机候选中锁定 3 个核心和 2 个特效；锁定后，本局技能池不再换人。
- 选项界面只保留名称、类型和勾选状态；可以“就选这些·开战”或“换一批”，升级选择只显示技能名、当前等级和 `+1`。
- 后续升级只从已锁定的 5 个技能中随机给出选择；核心法宝最高 5 级，额外特效为有限等级。
- 左侧技能条可查看 7 个技能位；“猴毛分身”卡片可直接点击触发原型主动效果。

管理员调试链接在地址后加 `?admin=1`，例如：

```text
/prototype-2d/index.html?admin=1
```

管理员面板提供暂停/继续、单步 tick、生成测试妖、重开、无敌、判定层、状态快照和事件日志。它是测试入口，不是权限系统。

## 本轮验证

- 18×32 米逻辑场地映射到 2D 俯视画面，页面比例固定为竖屏 9:16。
- 50 Hz 固定 tick。
- 悟空：2.6 米、110° 扇形、0.8 秒攻击周期、单次最多 6 个目标；动作分为前摇、有效段和收势。
- 悟空初版包含桃脸金箍、红金服饰、尾巴和金箍棒；小妖按牛妖、狐妖、猪妖和山怪方向使用不同色块与轮廓。
- 小怪：追击、接触伤害、击退、死亡；每 6 秒尝试生成 2 个，最多 32 个。
- 三分钟观察局、死亡重开和障碍物遮挡。
- 技能构筑、升级节点和技能快照会写入管理员事件日志。
- 每个浏览器独立运行，不包含多人同步或共享战斗状态。

这个原型回答的是“竖屏 2D 移动、基础战斗和首个攻击动作是否成立”，不代表正式引擎方案、最终美术、正式账号权限或 G1 通过。
