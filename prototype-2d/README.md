# 尸潮：最后一夜 · 网页原型

横屏 2D Canvas 搜打撤原型。网页单局 **300 秒**，生命归零失败；坚持到计时结束即撤离成功。结算会冻结战斗，可以立即重开。

## 运行与操作

双击 `index.html`，或通过静态文件服务器打开。页面与 `skills.js`、`city-map.js`、`house-system.js`、`loot-system.js` 保持同目录，无须安装依赖。

- 电脑：WASD / 方向键移动，按住 Space 手动开火，R 换弹，E 搜索物资箱，P / Esc 暂停。
- 手机：横屏使用左侧移动摇杆，按住右侧开火按钮手动射击。
- 瞄准辅助只负责跟踪视野内目标；没有开火输入时不会自动射击。
- 枪械显示当前弹匣 / 备弹。突击步枪 30/90，冲锋枪 36/108，霰弹枪 8/32；换枪会带入该枪的弹匣与备弹。
- 接触升级道具球会获得或强化被动技能；同类道具重复拾取会提升等级，不弹出三选一窗口。
- 暂停、失焦和结算时停止战斗并清理移动输入；拾取升级不会暂停战斗。

## 探索与品质

- 1440×2560 城市世界，原地图四倍面积，镜头跟随；道路和房屋之间可以绕行。
- 每块非街道地皮只有一栋房屋，房屋有住宅、商店、院落、高楼和毁坏建筑等类型，尺寸按人物比例放大。
- 室内和街区使用同一张地图、同一坐标和同一鸟瞰视角。角色直接从门窗开口走入走出，不加载第二场景；屋顶只在当前房屋位置隐藏。
- 房内家具、墙体、门窗是实际碰撞体；感染者会从门和窗进入，并使用室内通道绕开家具。
- 房屋搜索点标记为“物资箱”，每箱每局只搜索一次；搜索结果和未拾取物资在进出房屋后保留。
- 房内仍有感染者压力，撤离倒计时持续推进。
- 室外品质：普通 80%、精良 20%；房内品质：精良 40%、稀有 45%、史诗 15%。
- 品质效果倍率：普通 1、精良 1.2、稀有 1.5、史诗 1.9。实际用于枪械伤害和道具效果，离散数量取整数。
## 阿皮式物资箱

搜索物资箱会一次展示四类可携带物资：**披萨、牛奶、弹药、杂物**。它们是搜打撤背包物资，不会变成升级道具球，也不会自动变成枪械。

- 背包容量为 6 格（披萨占 2 格，其余各占 1 格）。靠近掉落物会自动装包；背包满时物资留在地面。
- 点击射击按钮左侧的小背包按钮（或按 `B`）打开 6 格背包。按住格内物资拖动可以调整顺序；拖出背包窗口范围会把物资丢回当前地图，丢弃后仍可重新拾取。
- 搜索窗口只在物资被识别后允许手动带入背包；窗口打开时新物资不会被角色站位自动拿走，关闭后未带走的物资继续留在地图。
- 弹药拾取增加当前枪械的备弹；披萨和牛奶恢复生命；所有物资都记录在本局背包中。
- 地图绿色撤离区会显示在状态中。五分钟成功时快照保存背包物资；死亡时背包和本局撤离记录清空。
- 击杀感染者不会掉落枪械、普通道具或升级球，只保留 0.5% 概率的一次性临时增益：2 秒无敌、5 秒攻速翻倍、5 秒弹药效果提升两级。

## 道具球构筑与枪械

开局只有普通突击步枪与求生本能，留出四个道具槽和两个增益槽。定时补给和普通场景掉落产生升级道具球；枪械拾取只通过普通枪械掉落或调试接口，物资箱不产枪械。

- 首次捡到道具获得一级，重复同类球提升一级。核心最高五级，增益最高三级。
- 更高品质同类球改善品质；较低品质重复球保留已有品质。满级时仍允许品质提升。
- 类别满槽的新道具、满级且品质没有提升的重复球转为治疗，并给出反馈。
- 经验继续推进幸存者等级、额外补给和口粮治疗，不再提供三选一弹窗。
- 感染者会低概率掉落方形战斗消耗物：2 秒无敌、5 秒攻速翻倍或 5 秒弹药强化；效果计时结束后自动失效，消耗物与升级球分开显示。
- 突击步枪射击均衡，冲锋枪射速更快，霰弹枪同时发射多弹丸；拾取同等或更好品质的不同枪械可换装。
- 低于当前枪械品质的枪转为医疗；相同枪且品质未提高时也转医疗，避免自动降低装备品质。
- 重开清空成长道具、品质、枪械和全部房屋搜索状态。

## 五分钟压力

开局八名普通感染者，基础速度 38 像素/秒、刷怪 0.8/秒。波次、敌人上限和尸潮间隔随 300 秒平滑增加，最后 30 秒进入撤离压力。

室外感染者上限桌面 160、触屏 104；室内单独限量。弹丸、粒子、经验、道具球和地雷有数量上限。感染者和补给避开建筑与幸存者碰撞体。

## 管理员验收

地址添加 `?admin=1` 可打开 DEV 面板：密度、暂停、单步、感染者生成、生成道具、清场、无敌、判定层、快照、重开。这是原型调试入口，不是账号权限。

仅管理员页面公开 `window.__LAST_NIGHT_DEBUG__`：

- `snapshot()`：战斗、构筑、品质、当前枪械、场景、房内箱子和地图状态。
- `step(seconds)`：固定步长模拟推进；可在暂停时验收，结算后停止。
- `spawnLoot(typeOrSkillId = "random", quality?, x?, y?)`：生成道具；显式品质为调试覆盖，正式掉落按所在场景规则。
- `interact()`：尝试当前入口、箱子或出口交互。
- `state`、`build`、`map`、`houses`、`loot`、`modifiers`：读取实际运行状态和战斗属性。

本地模拟与浏览器验收不代表微信真机、线上发布或真人试玩。小程序按用户安排暂停更新，继续使用旧规则。

## 手绘卡通角色

`assets/cartoon-rig-v1.png` 是透明角色部件图集：幸存者与四类感染者各有头/躯干、手臂、腿/鞋部。`character-atlas.js` 保存裁切边界，`character-art.js` 负责缓存、分层和运动渲染；图集失败时使用矢量兜底。

主角采用无帽平民日常服装；身体和头保持直立，只有手臂、步枪和双腿按动作变化。感染者支持走路、跑步、跳跃和低姿态爬行。
