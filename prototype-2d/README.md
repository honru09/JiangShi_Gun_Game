# 尸潮：最后一夜 · 网页原型

竖屏 9:16 Canvas 生存战斗。坚持 **180 秒**撤离成功，生命归零失败；结算冻结战斗，可直接重开。浏览器各自独立运行。

## 运行与操作

双击 `index.html`，或通过静态文件服务器打开。页面与 `skills.js`、`city-map.js`、`house-system.js`、`loot-system.js` 保持同目录，无须安装依赖。

- 电脑：WASD / 方向键移动，E 进入房屋、搜箱或返回街区，P / Esc 暂停。
- 手机：拖动左下摇杆；靠近交互位置后点击右侧按钮。
- 自动锁定未被建筑挡住的感染者并射击，身体与头直立、持枪手臂转动、双腿随实际位移迈步。
- 接触道具球拾取，球颜色代表品质。暂停页可查看当前道具说明。
- 暂停、失焦和结算时停止战斗并清理移动输入；拾取升级不会暂停战斗。

## 探索与品质

- 1440×2560 城市世界，原地图四倍面积，镜头跟随；道路和房屋之间可以绕行。
- 房屋有可交互门口，进入独立房间后可自由移动，靠近物资箱搜索，靠近出口返回街区。
- 每箱每局只搜索一次，进出房屋保留搜索结果、掉落和感染者；离开场景清除临时弹丸与特效。
- 房内仍有感染者压力，撤离倒计时持续推进。
- 室外品质：普通 80%、精良 20%；房内品质：精良 40%、稀有 45%、史诗 15%。
- 品质效果倍率：普通 1、精良 1.2、稀有 1.5、史诗 1.9。实际用于枪械伤害和道具效果，离散数量取整数。
- 首次搜索房屋保证得到冲锋枪或霰弹枪，其他搜索点提供道具。

## 道具球构筑与枪械

开局只有普通突击步枪与求生本能，留出三个战术槽和两个增益槽。定时补给、击杀随机掉落、经验等级奖励与房内搜索产生道具球或枪械。

- 首次捡到道具获得一级，重复同类球提升一级。核心最高五级，增益最高三级。
- 更高品质同类球改善品质；较低品质重复球保留已有品质。满级时仍允许品质提升。
- 类别满槽的新道具、满级且品质没有提升的重复球转为治疗，并给出反馈。
- 经验继续推进幸存者等级、额外补给和口粮治疗，不再提供三选一弹窗。
- 突击步枪射击均衡，冲锋枪射速更快，霰弹枪同时发射多弹丸；拾取同等或更好品质的不同枪械可换装。
- 低于当前枪械品质的枪转为医疗；相同枪且品质未提高时也转医疗，避免自动降低装备品质。
- 重开清空成长道具、品质、枪械和全部房屋搜索状态。

## 三分钟压力

开局八名普通感染者，基础速度 38 像素/秒、刷怪 0.8/秒。每 15 秒提升波次，30/45/60 秒加入疾跑/重型/爆囊感染者。首批额外尸潮 15 秒到达，此后每 10 秒一批；最后 30 秒缩至每 6 秒一批。

室外感染者上限桌面 160、触屏 104；室内单独限量。弹丸、粒子、经验、道具球和地雷有数量上限。感染者和补给避开建筑与幸存者碰撞体。

## 管理员验收

地址添加 `?admin=1` 可打开 DEV 面板：密度、暂停、单步、感染者生成、生成道具、清场、无敌、判定层、快照、重开。这是原型调试入口，不是账号权限。

仅管理员页面公开 `window.__LAST_NIGHT_DEBUG__`：

- `snapshot()`：战斗、构筑、品质、当前枪械、场景、房内箱子和地图状态。
- `step(seconds)`：固定步长模拟推进；可在暂停时验收，结算后停止。
- `spawnLoot(typeOrSkillId = "random", quality?, x?, y?)`：生成道具；显式品质为调试覆盖，正式掉落按所在场景规则。
- `interact()`：尝试当前入口、箱子或出口交互。
- `state`、`build`、`map`、`houses`、`loot`、`modifiers`：读取实际运行状态和战斗属性。

本地模拟与浏览器验收不代表微信真机、线上发布或真人试玩。小程序按用户安排暂停更新，继续使用旧规则。
