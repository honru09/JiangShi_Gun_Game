# 尸潮：最后一夜 · 网页原型

竖屏 9:16 Canvas 生存战斗。每局目标是坚持 **三分钟**，倒计时结束后撤离成功；生命归零则失败。两种结算都冻结战斗，可直接重开。浏览器各自独立运行。

## 运行与操作

双击 `index.html`，或通过静态文件服务器打开 `prototype-2d/index.html`。`skills.js` 应与页面保持在同一目录，无须安装依赖。

- 电脑：WASD / 方向键移动，P / Esc 暂停或继续；也可点击暂停按钮。
- 手机：拖动左下角摇杆；输入幅度决定走路或跑步的速度。
- 突击步枪自动锁定最近的感染者，显示枪口火光、后坐、弹道与命中反馈。
- 幸存者的身体和头始终直立，只有双臂与步枪转动瞄准；双腿按实际移动速度交替迈步，撞到边界会收腿站稳。
- 所有感染者头在上、脚在下，使用弯膝拖步、僵直手臂与轻微身体晃动；整个人不会随追击方向旋转。
- 暂停、升级和结算时动作冻结；切换窗口、隐藏页面和摇杆取消会清理移动输入。

## 三分钟节奏

开局 8 名普通感染者，基础速度 38 像素/秒；刷怪速率从 0.8/秒逐渐上升。每 15 秒提升波次，30 秒出现疾跑，45 秒出现重型，60 秒出现爆囊。首批额外尸潮在 15 秒到达，此后每 10 秒一批；最后 30 秒提示撤离并将尸潮间隔缩至 6 秒。普通速度逐渐提高至 1.7 倍。

普通密度下刷怪最高 8/秒。存活硬上限为桌面 160 / 触屏 104，弹丸、粒子、经验拾取物和地雷也有数量上限。感染者从边缘生成，与幸存者至少相距 220 像素，并避开已有感染者。

## 七槽构筑

开局仅携带突击步枪 + 求生本能，另留 3 个战术槽和 2 个增益槽。拾取感染者掉落的经验后升级，每次随机提供最多 3 项技能，选择一项获得或强化。

- 核心：散射、灼烧、电弧连锁、环绕旋刃无人机、感应地雷、穿甲。
- 增益：移速、生命/减伤、经验吸附/收益、脱战恢复、濒危移速/射速、升级恢复/生命上限。
- 初始升级需求 5 经验，后续按等级增长；核心最高 5 级，增益最高 3 级。
- 未拥有技能占用对应空槽，首次获得为 1 星；已拥有技能提升 1 星。某类槽位满后不再出现该类新技能，满星技能不再出现。
- 可用选项少于 3 项时按实际数量展示；全部技能满星后，升级转为医疗补给。一次获得多级经验时，连续完成选择才恢复战斗。
- 底部按基础、战术、增益分组，仅展示短标识与星级；暂停页面可查看完整技能名称与说明。重开清空成长技能。

## 管理员验收

地址后添加 `?admin=1`，打开 DEV 面板。可调密度、暂停、单步 1/60 秒、生成感染者、强制升级、清场、切换无敌/判定层并复制快照。此入口用于原型调试，不是账号权限系统。

仅管理员页面公开 `window.__LAST_NIGHT_DEBUG__`：

- `snapshot()`：倒计时、结果、构筑、场上数量、性能与射击统计、玩家身体/胳膊/步态、枪口位置。
- `step(seconds = 1 / 60)`：按固定步长推进，允许在暂停时验收；升级和结算时停止，单次最多推进 600 秒。
- `state` / `build` getter：管理员测试可读取和配置运行态。
- `config` getter：读取三分钟时长与数量上限等配置。

本地模拟和浏览器检查不代表微信真机、正式上线或真人试玩结果。
